## Core judgments

- PI-Desktop is a local-first desktop client for an AI coding agent.
- The workspace, agent runtime, permission boundaries, and model configuration must be visible and inspectable.
- The everyday coding experience takes priority over remote control, cloud gateways, and automation that cannot be audited.
