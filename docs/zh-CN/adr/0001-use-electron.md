# ADR 0001：使用 Electron 作为桌面外壳

> **翻译说明：** 本页是与 [英文源决策](/adr/0001-use-electron) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-07-25

## 上下文

PI-Desktop 需要桌面分发、本地权限控制、会话 UI 以及系统集成能力。主要候选方案是 Electron 和 Tauri。

## 决策

采用 **Electron** 作为桌面外壳。

## 理由

1. 贴近已调研的 ChatGPT Desktop / WorkBuddy 的技术路径，便于借鉴其工程经验
2. Node 生态与 pi 的 TypeScript 运行时契合度更高
3. 原生模块、调试工具链与打包资源更为成熟
4. 团队当前路线图明确倾向 Electron

## 后果

### 正面
- 开发速度快
- 代理运行时可直接放在主进程/Node 侧
- 后续集成 pty、sqlite 与自动更新更为常规

### 负面
- 相比 Tauri，包体积与内存占用更大
- 需要严格执行 Electron 安全基线

## 备选方案

- Tauri 2：更轻量，但与当前路线图不一致；不作为 MVP 基线
