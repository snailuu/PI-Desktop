# ADR 0004：MVP 中不实现远程 Gateway

> **翻译说明：** 本页是与 [英文源决策](/adr/0004-no-gateway-in-mvp) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-07-25

## 上下文

LiveAgent 等产品提供了远程 WebUI/Gateway。PI-Desktop 是否应在第一阶段加入远程控制能力，是一个需要权衡的取舍。

## 决策

MVP **不会**构建远程 Gateway / 基于浏览器的远程控制。

## 理由

1. 它与本地优先的桌面端闭环目标在优先级上存在冲突
2. 远程链路会显著增加认证、同步和安全方面的复杂度
3. 我们应先证明本地代理的 UX 和权限模型能够成立

## 后果

### 正面
- 范围收敛
- 安全模型更简单

### 负面
- 短期内无法通过浏览器对本地代理进行远程控制

## 后续

若要构建远程能力，必须新增一个独立的 ADR，并为其设立专属里程碑。
