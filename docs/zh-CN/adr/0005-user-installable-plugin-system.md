# ADR 0005：用户可安装插件系统

> **翻译说明：** 本页是与 [英文源决策](/adr/0005-user-installable-plugin-system) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

## 上下文

仅有内置功能还不够。用户需要安装和开发插件来扩展：

- 命令
- 面板
- 代理工具
- 技能

## 决策

采用第一方**插件系统**：

- 基于目录的插件包
- `manifest.json` 贡献 + 权限声明
- 命令面板集成
- 代理工具注册支持
- 本地安装 / 启用 / 禁用 / 卸载
- 默认拒绝权限，显式授予

## 理由

1. 支持用户自定义，而无需 fork 应用
2. 比加载任意 Electron 主脚本更安全
3. 同时服务于 UI 扩展和代理扩展
4. 为后续插件市场协议留出空间

## 后果

### 积极
- 可扩展的产品面
- 清晰的贡献模型
- 与技能/工具生态对齐

### 消极
- 额外的架构和安全复杂度
- 需要管理 UI、校验和审计

## 范围控制

- MVP 优先本地插件加载，而非插件市场
- 首批贡献类型：命令 / 面板 / agentTools / 技能
- 插件默认隔离并受权限管控
