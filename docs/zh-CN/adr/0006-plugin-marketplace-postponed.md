# ADR 0006：推迟插件市场；优先构建本地插件运行时

> **翻译说明：** 本页是与 [英文源决策](/adr/0006-plugin-marketplace-postponed) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受

## 上下文

我们需要插件扩展能力，而在先构建插件市场还是先构建本地插件运行时之间存在选择。

## 决策

1. 首先完成**本地插件系统**（加载、权限、命令、工具、生命周期）
2. 将**插件市场**视为延后能力；先冻结协议与数据模型
3. 插件市场第一版只做浏览 / 下载 / 校验 / 手动更新，不包含交易或社交功能

## 理由

1. 没有稳定的运行时，插件市场只会分发无法安全运行的包
2. 本地插件已满足核心的“用户自定义”需求
3. 插件市场涉及信任、签名和远程供应链，复杂度显著更高

## 后果

### 正面
- 核心路径更稳定
- 可以先通过示例插件和内部渠道分发进行验证

### 负面
- 短期内没有一键商店体验

## 后续触发条件

R1/R2 完成且插件 API 基本稳定后，启动 R4 Marketplace。
