# ADR 0007：插件分发包格式采用 .piplug（zip）

> **翻译说明：** 本页是与 [英文源决策](/adr/0007-plugin-package-format) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-07-25

## 上下文

我们需要一种便于本地分享和插件市场下载的插件包格式。

## 决策

采用 `.piplug` 作为产品层面的分发包扩展名。其内容为 zip 归档，根目录下包含 `manifest.json`。

## 理由

1. 实现简单，跨平台
2. 便于进行校验和 / 签名
3. 对开发者友好（可在本地解压检查）

## 影响

### 积极影响
- 工具链轻量
- 可与本地目录包共用统一的校验逻辑

### 消极影响
- 必须防范 zip slip 和超大包攻击

## 约束

- 安装前必须执行路径安全检查
- 插件市场分发包必须至少提供 sha256
