# ADR 0009：英文优先的全球化

> **翻译说明：** 本页是与 [英文源决策](/adr/0009-english-first-globalization) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-07-25

## 上下文

PI-Desktop 面向全球用户并开放贡献。仅提供中文的产品界面会阻碍国际采用和插件生态系统的增长。

## 决策

PI-Desktop 采用**英文优先**：

1. 产品 UI 默认语言：**英文**
2. 规格、ADR、代码注释、提交、issue、插件文档：**以英文为主**
3. 从 UI 早期工作开始就要求具备 i18n 框架
4. 其他语言区域（包括中文）是可选的包，而非事实来源

## 本地化规则

- 源字符串以英文存在
- 核心代码中不得硬编码非英文 UI 文案
- 语言区域包使用稳定的消息 ID
- 插件清单/文档建议使用英文；本地化字段可在后续可选提供

## 后果

### 正面
- 具备面向全球的基线
- 更易于外部贡献
- 插件生态系统的语言默认值更清晰

### 负面
- 中文文案成为翻译层，而非主要创作格式
