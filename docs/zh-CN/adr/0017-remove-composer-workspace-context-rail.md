# ADR 0017：移除输入框工作区上下文栏

> **翻译说明：** 本页是与 [英文源决策](/adr/0017-remove-composer-workspace-context-rail) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-07-26

## 上下文

D056、D066、D067 和 D087 确立了一个附加于输入框的栏，用于显示当前项目、Local 环境标签以及尽力而为的 Git 分支元数据。后续的视觉优化还为该栏分配了专门的高度、间距、表面和层级规则。

项目条目重复了已可通过首页主视觉区、侧边栏和 Projects 目的地获得的导航。Local 和分支只是被动标签，而当分支检测未产生值时，渲染器会显示 `main`。这使得该栏占用空间，却未提供可靠或独有的控制。

## 决策

首页和对话停靠型的输入框变体不再渲染项目、Local 或分支的上下文外壳。输入框外壳不再为已移除的栏预留高度、接缝、分隔线或层级。

此决策仅改变呈现方式。项目选择、活动工作区持久化、会话项目绑定、Git 分支检测、Projects 元数据以及工作区范围的工具均保持不变，并仍可通过其现有的非输入框界面使用。

本决策取代 D052、D055、D056、D066、D067 和 D087 中与工作区芯片和上下文栏相关的部分。它作为 baseline 0.4.4 中的 D095 记录。

## 后果

- 输入框在每种工作区状态下都是单一的提示输入界面。
- 项目选择不再拥有输入框本地的快捷键。
- 现有的项目导航继续通过首页主视觉区、侧边栏和 Projects 目的地获得。
- 分支元数据仍在 Projects 使用它的地方保持可见，不再有误导性的输入框回退。
- 规格和视觉回归场景断言该栏不存在。

## 备选方案

### 保留完整的栏

被否决，因为其三个值中有两个是被动的，且项目操作重复了现有导航。

### 仅保留项目操作

被否决，因为这会为一个周围外壳中已经可用的操作保留一个专门的输入框界面。

### 仅在一个输入框变体中隐藏该栏

被否决，因为首页和对话布局不一致会保留额外的界面装饰，并使提示输入界面在对话记录开始时发生位移。
