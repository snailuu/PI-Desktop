# ADR 0037：在 Electron 主进程中解析项目指令

> **翻译说明：** 本页是与 [英文源决策](/adr/0037-project-instruction-chain) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-07-30
- 相关：[代理运行时](/zh-CN/spec/03-runtime/02-agent-runtime)

## 上下文

PI-Desktop 最初只在创建运行时加载 `<project root>/AGENTS.md`。这遗漏了 monorepo 中针对特定目录的规则，也没有为使用 `CLAUDE.md` 的项目提供兼容路径。让模型驱动的代理 sidecar 扫描工作区会削弱既有的边界，该边界将工作区文件访问限制在 Electron 主进程与主机核心中。

## 决策

1. Electron 主进程仅在会话绑定的项目根目录内解析指令；它绝不跟随其规范路径逃逸出该根目录的指令文件。
2. 全局文件 `~/.pi/agent/AGENTS.md` 在所有项目条目之前加载。设置管理这个固定路径。项目的 `AGENTS.md` 通过 Projects 视图中该项目的列表菜单操作进行管理；专用 IPC 仅接受由主机核心注册的项目根目录，绝不接受任意文件路径。
3. 对于每个项目目录，按以下顺序取第一个非空候选项：
   `AGENTS.override.md`、`AGENTS.md`、`CLAUDE.md`、
   `.claude/CLAUDE.md`。
4. 来源从根目录拼接到目标目录，UTF-8 内容上限为 32 KiB。越靠后、越接近的条目优先级越高，且每个来源在提示中都有标注。
5. 根链在创建运行时时加载。在文件路径工具执行之前，sidecar 可以通过 Electron 拥有的 `project.instructions.resolve` 本地代理请求特定路径的链。sidecar 不直接读取指令文件。
6. Electron 主进程随运行时启动元数据传递会话绑定的项目根目录，并在每次提示或压缩请求之前注册它。本地代理根据主进程拥有的绑定来解析目标路径，而不是为每个文件发起 `session.get` RPC。sidecar 仅为当前提示缓存每个项目根目录/目标目录对的一次解析声明。

## 后果

- 无需递归扫描工作区即可加载仓库范围的规则。
- 全局默认值无需项目即可编辑；项目指令仍可在仓库根目录中审查和版本化。
- 嵌套规则仅在代理访问匹配路径时可用。每个文件工具都会用该目标的完整链替换活动链，防止同级目录的规则泄漏到后续工具调用中。
- 路径特定解析是尽力而为的，并以两秒为上限。如果解析器或其宿主 RPC 不可用，工具会回退到基础链，而不是等待通用宿主 RPC 截止时间。
- 路径预检会记录自己的耗时以及缓存/回退标记，因此 `hostRttMs` 继续描述实际的主机工具调用。
- 根指令变更会在下一次提示时重建空闲运行时。嵌套规则会为未来的文件路径工具调用重新解析。
- 这个私有 sidecar 代理仍受限于会话 id 和路径，且 Electron 主进程会依据该会话的项目根目录进行验证。

## 备选方案

### 在启动时加载所有嵌套指令文件

已拒绝。大型 monorepo 可能注入无关规则，并在任务识别出相关目录之前就消耗模型上下文。

### 让 sidecar 扫描工作区

已拒绝。sidecar 会执行由模型指示的路径。工作区发现仍保留在 Electron 主进程中，以使既有的隔离边界保持明确。
