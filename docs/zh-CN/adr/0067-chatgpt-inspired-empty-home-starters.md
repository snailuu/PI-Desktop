# ADR 0067：受 ChatGPT 启发的空白首页起始引导

> **翻译说明：** 本页是与 [英文源决策](/adr/0067-chatgpt-inspired-empty-home-starters) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：被 D206 取代
- 日期：2026-08-07
- 决策者：PI-Desktop 主机核心
- 修订：D204 及 ADR 0066 中与卡片相关的条款

> 此历史决策保留以供追溯。起始卡片网格在评审后被移除；D206 将空白首页恢复为主视觉区域、可选的新手引导清单，以及直接位于底部的输入框。

## 上下文

D204 引入的底部直接输入框解决了空白首页的布局问题，但使对话面板的中心区域在视觉上显得空泛。首次使用的开发者仍需先自行构思提示词，才能看到 PI-Desktop 能做什么。所要求的方向是借鉴 ChatGPT 空白对话面板那种易于上手的层级结构，并针对本地编码工作进行调整，而非面向消费级内容或推广模板。

## 决策

1. 在空白首页的主视觉区域与可选的新手引导清单之间添加一个四卡片起始网格：探索代码库、构建功能、修复缺陷、审查变更。
2. 卡片保持紧凑、单色、本地化，并面向开发者。它们使用共享的图标、边框、表面、阴影与动效 token。
3. 激活卡片仅会预填充并聚焦现有的底部输入框。它绝不会发送提示词、创建会话回合或更改当前会话模式。
4. 保持 D204 的单一可滚动首页内容区域与底部预留的输入框不变。窗口较矮时仍须滚动内容，而不是让输入框覆盖内容。

## 后果

- 空白首页拥有了有用的视觉层级，同时未移动或复制主输入框操作。
- 起始提示词保持可编辑，因此用户可在发送前补充项目特定的上下文。
- 四张卡片仅增加渲染器本地的呈现与本地化文案；无需任何 IPC、存储或协议变更。
- 起始网格在窄窗口中折叠为单列，并保持在现有首页滚动容器内。

## 已考虑的替代方案

### 保留仅有主视觉区域的空白状态

已拒绝。它保留了直接进入的体验，却使中间面板不必要地空泛，并且没有为新用户提供任务词汇。

### 自动提交选中的起始提示词

已拒绝。起始引导是引导，而非隐式操作。预填充保留了用户控制权，并让用户能够添加路径、约束或验收标准。

### 恢复此前的氛围式建议行

已拒绝。此前那一行过于装饰化，并且使用了不同的提示词选择模型。新的网格紧凑、明确面向开发者，并将输入框保持为唯一的发送面板。
