# ADR 0082：本地化且页面自适应的插件面板外框

> **翻译说明：** 本页是与 [英文源决策](/adr/0082-localized-plugin-panel-chrome) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

## 状态

已接受

## 上下文

插件面板托管在各自的 Electron 窗口中。其标题栏此前只接收 manifest 提供的单个字符串，而预加载外框默认使用深色表面。这使面板与 PI-Desktop 当前的语言设置脱节，也让浅色的插件页面看起来像是配了一个毫不相干的黑色页眉。

## 决策

1. `ui.title` 既可接受现有的字符串形式，也可接受同时包含 `en` 与 `zh-CN` 字符串的本地化对象。宿主会依据当前 PI-Desktop UI 语言解析该值，并回退到所提供的另一个标签，最后回退到 manifest 名称。
2. 宿主会将当前浅色/深色主题传递给面板窗口。预加载脚本会采样已加载文档的 body/document 计算后背景色与前景色用于标题栏；当页面为透明时，则使用宿主主题。
3. 标题栏仍保留在封闭的、由预加载脚本持有的 Shadow DOM 中。插件 CSS 可以选择页面表面，但无法触及或重设宿主控件的样式。
4. 现有的字符串型 manifest 与现有面板尺寸保持兼容。

## 影响

- 插件作者可以在一个 manifest 中同时提供英文与简体中文的面板标题。
- 面板外框与自定义插件页面以及宿主显式设置的主题偏好保持视觉一致。
- 首次绘制后颜色发生变化的页面不会被持续检测；插件应在 `DOMContentLoaded` 之前设置其页面表面。
