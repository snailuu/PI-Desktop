# ADR 0093：保留严格的 46px 插件拖拽带与极简胶囊

> **翻译说明：** 本页是与 [英文源决策](/adr/0093-plugin-panel-strict-drag-band) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- Date: 2026-08-17
- Deciders: PI-Desktop core
- Related: D235, ADR 0092

## 上下文

插件自有的面板表面引入了紧凑的宿主胶囊，但其布局约定必须保持显式。无边框窗口仍需要可靠的拖拽区域，且顶部带不能接收插件点击。宿主不得为了标题、平台特定控件行或装饰性边框而扩大该带。开发作者也需要一个可见的约束提醒。

## 决策

1. 每个插件面板为透明的宿主拖拽带精确保留 46 CSS px。正常流内容按相同数值偏移；固定和 sticky 的插件 UI 使用 `--pi-plugin-titlebar-height: 46px`。
2. 拖拽带使用 `-webkit-app-region: drag`，并在这 46px 内阻断插件的指针交互。宿主胶囊通过 `-webkit-app-region: no-drag` 退出该规则，因此其三个按钮仍可点击。
3. 宿主不渲染面板标题。开发面板显示一条本地化的、非交互式提醒，说明顶部 46px 除胶囊外仅用于拖拽；生产面板不显示该提醒。
4. 胶囊固定于 46px 带内的右上角，并保持为极简的闭合 Shadow DOM 表面：三个控件、细微边框和随页面自适应的背景，不使用重阴影或模糊效果。其私有的、经发送方校验的窗口控制通道、本地化标签、焦点行为、减弱动效行为以及 `window.pluginBridge` 保持不变。

## 穿透绘制的可选启用

需要全幅表面的面板可以声明 `<meta name="pi-plugin-chrome" content="v3">`。宿主保持相同的 46px 几何尺寸和胶囊，但将一个全宽的本地拖拽矩形替换为空白区域的拖拽片段。标准控件以及标记了 `data-pi-plugin-no-drag` 的元素会在该映射中形成空洞，因此页面在有元素存在之处可以绘制并接收指针事件，而空白区域仍可拖拽窗口。现有的 `v2` 面板为兼容性保留上述严格不可点击的顶部带。

## 影响

- 插件作者在每个桌面平台上获得稳定的 46px 布局与交互约定。
- 除宿主胶囊外，顶部带刻意对插件按钮不可用；插件工具栏应使用文档化的拖拽/非拖拽规则。
- 开发作者能看到该约束，而生产面板保持表面简洁。
- 胶囊的视觉分量更小，且不能超出拖拽带。

## 备选方案

### 让拖拽带随胶囊增大

拒绝，因为可变宽度的宿主带会改变插件布局，并使同一面板在不同平台或未来的界面外框版本中表现不一致。

### 默认让所有插件内容在拖拽带内接收点击

作为默认行为被拒绝，因为无边框窗口的拖拽将变得不可靠，作者也可能把顶部条带误认为普通可交互内容。`v3` 的启用是刻意显式的，并保持原有 `v2` 行为不变。

### 恢复宿主渲染的面板标题

拒绝，因为插件拥有可见的面板层级；宿主只需要三个原生窗口操作和开发约束提醒。
