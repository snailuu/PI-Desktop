# ADR 0096：扁平化设置目录并就近放置插件市场源配置

## 上下文

已实现的设置导航栏已经增长到九个条目，其中包括一个独立的
`Extensions` 目标页，用于承载两个插件市场源控件。该导航栏还把目标页
包装在 `Personal`、`Integrations` 以及一个隐式的系统分区中。这些标题重复了
目标页标签已经表达的信息，而 `Extensions` 与拥有插件管理的应用外壳目标页
具有相同的可见名称。

设置信息架构已经定义了八个有用的目标页。插件市场源的选择是插件市场的事务，
应当紧邻它所控制的目录，而不是与外观、供应商或项目设置相邻。

## 决策

保留全页设置外壳，并以如下精确顺序渲染一个扁平、可搜索的目录：

1. 基础
2. AI
3. 快捷键
4. 指令
5. 模型配置
6. 导入
7. 项目归档
8. 信息

移除导航分组标题以及设置中的 `Extensions` 目标页。
将官方/镜像/自定义插件市场源选择器——包括自定义目录 URL 字段和当前生效源状态——
移入应用外壳的 `Extensions → Marketplace` 界面。共享的设置搜索索引中
只包含这八个设置目标页；插件市场搜索与控件仍归扩展页面所有。

不涉及 IPC、主机协议、存储、供应商、插件权限或项目归属契约的变更。

## 影响

- 设置只有一个视觉层级，相互竞争的标签更少。
- 导航栏符合已冻结的八目标页信息架构，不再重复扩展页面的名称。
- 插件市场源的变更仍然可用在用户浏览和安装包的上下文中，
  具有相同的持久化和刷新行为。
- 设置搜索不再深度链接到插件市场源行；扩展页面是该界面的所有者。
- 截图采集场景和插件市场 E2E 步骤必须从 Extensions → Marketplace 打开源
  选择器。

## 备选方案

### 保留三个分组标题

已拒绝，因为分组并没有增加第二层有用的导航层级；它们
使导航栏更高，并重复了目标页标签的含义。

### 将设置的 `Extensions` 重命名为 `Marketplace`

已拒绝，因为这会保留一个仅含单张卡片的设置目标页，并且仍然
把插件市场浏览与插件市场配置分开。

### 移除插件市场源配置

已拒绝，因为对于无法访问官方源的网络以及开发/私有目录，
镜像和自定义目录源是必需的。
