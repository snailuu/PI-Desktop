# ADR 0097：将全局默认值归入 AI 设置目的地

> **翻译说明：** 本页是与 [英文源决策](/adr/0097-place-global-defaults-under-ai-settings) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-08-18
- 决策者：PI-Desktop 核心
- 相关：D166、D238、D239、ADR 0096

## 上下文

扁平化的设置目录去除了冗余的导航层级，但 Basics 页面仍然拥有一个默认值卡片，其中包含默认操作模式、命令 shell 以及 Enter 发送偏好。这些控件改变的是代理行为而非应用外观，因此它们所在的位置使 Basics 页面将视觉偏好与全局 AI 行为混在一起。

## 决策

保持八个目的地的设置目录不变。Basics 拥有外观卡片和平台支持的关闭行为。**全局 AI / AI** 目的地拥有权限卡片和默认值卡片，其行项为：

- 默认操作模式（Agent / Plan / Goal）
- 命令 shell 选择及其宿主支持的兜底状态
- Enter 发送

模型配置目的地继续拥有默认供应商/模型选择器，因为它与供应商就绪状态和模型身份相耦合。此更改仅移动渲染器内容和设置搜索归属；持久化设置、宿主 API、运行时语义和深度链接契约均不改变。

## 后果

- Basics 具有聚焦的视觉和应用偏好范围。
- 全局 AI 呈现用户预期影响代理回合的行为控件。
- 设置搜索将模式、命令 shell 和 Enter 发送查询路由到 AI。
- 现有持久化设置和运行时行为保持不变。

## 备选方案

### 将默认值保留在 Basics 中

被否决，因为该卡片将外观与代理执行行为混在一起。

### 添加单独的行为目的地

被否决，因为这会为三个密切相关且已在 AI 中有明确归属的控件扩展扁平目录。

### 将控件移至模型配置

被否决，因为操作模式、命令 shell 和 Enter 发送是全局交互行为，不依赖于供应商/模型就绪状态。
