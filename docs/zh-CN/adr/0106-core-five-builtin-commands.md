# ADR 0106：仅保留五个核心内置命令

> **翻译说明：** 本页是与 [英文源决策](/adr/0106-core-five-builtin-commands) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-08-19
- 决策者：PI-Desktop core
- 相关：D250、ADR 0024、ADR 0034、`04-ux/04-builtin-commands.md`

## 背景

第一方命令注册表已增长到十五个条目，而输入框的 `/` 菜单和全局搜索的 Commands 区段中暴露的若干操作，其实已经有专门的 UI 界面。它还保留了一些仅用于分派的别名，以及不再注册的、仅存在于规格中的 ID。保留这些条目使命令发现变得嘈杂，并暗示了应用并未一致实现的契约。

## 决策

1. 将第一方注册表冻结为恰好以下五个 ID：
   `builtin.session.new`、`builtin.agent.compact`、`builtin.mode.agent`、
   `builtin.mode.plan` 和 `builtin.mode.goal`。
2. 保留对应的别名 `/new`、`/compact`、`/agent-mode`、`/plan-mode`
   和 `/goal-mode`。模式别名保留现有的一次性形式，可携带提示正文；它们先切换模式，然后把剩余文本作为可见的用户回合发送。
3. 从内置注册表和渲染器分派中移除会话删除、中止、项目、设置、插件、日志、会话重命名、命令面板、重新加载窗口和 DevTools 条目。同时移除遗留的 `newChat`、
   `openProject` 和 `openSettings` 分派别名。
4. 保持插件命令贡献和专门的 UI 操作独立于该注册表。旧的内置 ID 不是兼容别名；它不再是第一方命令或输入框内置命令。

## 后果

- 全局搜索和输入框的 `/` 菜单拥有更小、更稳定的第一方命令界面。
- 新建任务、压缩和模式切换仍然是键盘优先和斜杠优先的工作流。模式的提示正文契约保持不变。
- 中止、删除、项目、设置、插件、日志、重新加载和 DevTools 操作仅在这些工作流仍然存在的地方通过其专用控件或界面提供；它们不再作为内置命令可被发现。
- 除非其他命令来源贡献了同名命令，否则未知的旧别名会作为普通的斜杠文本继续传递。

## 考虑过的替代方案

### 在注册表中保留所有应用导航命令

已否决：项目、设置、插件和诊断类操作与现有界面重复，并在全局搜索中与面向任务的命令相互竞争。

### 将旧 ID 保留为隐藏的兼容别名

已否决：隐藏别名仍会扩展命令契约，并使失效条目仍可从过期的 UI 或复制的调用中执行。被移除的命令不应显示为可发现，也不应被视为受支持的内置命令。
