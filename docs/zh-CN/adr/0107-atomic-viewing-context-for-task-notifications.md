# ADR 0107：使当前会话任务通知抑制具备原子性

> **翻译说明：** 本页是与 [英文源决策](/adr/0107-atomic-viewing-context-for-task-notifications) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受

- 决策者：PI-Desktop 主机核心

## 上下文

任务完成有两个对渲染器可见的效果：转录记录收到一条代理生命周期事件，并且 Electron 可能从 `session.endTurn` 收到一条持久化通知。渲染器此前将每一个 `agent_end` 或终止性 `error` 事件都视为侧边栏未读结果，即使当前聚焦的对话已经显示了该结果。另外，活动会话查看提示是通过异步 React effect 传递的，因此快速回合可能在 Electron 收到该提示之前就已完成。

## 决策

1. 将未读的 `task.completed` 和 `task.failed` 通知记录视为终止性侧边栏标记的唯一来源。代理生命周期事件继续驱动运行状态、转录记录更新以及对话内回合结果卡片，但它们本身绝不产生未读侧边栏结果。
2. 在渲染器发起的 `agent/prompt` 请求上携带一个可选的 `viewingSessionId` 快照。Electron 验证它是否与所请求的会话完全匹配，并在异步回合设置之前安装它。缺失、为 null 或不匹配的快照会清除该提示，并安全失败为发送通知。
3. 保留现有的查看上下文 IPC 和由主进程拥有的可见性/焦点门控。仅当一个可见且聚焦窗口中的确切完成会话才允许抑制；后台、隐藏、未聚焦或未知状态会创建持久化通知，并保留原生投递行为。

## 后果

- 保持停留在某个对话中的聚焦用户会看到转录记录中的完成结果，而不会出现重复的侧边栏标记、收件箱行或原生通知。
- 后台和未聚焦的会话保留持久化及原生的恢复通知。
- 提示请求新增一个附加的可选字段；省略该字段的旧调用方会安全失败，而不是使用陈旧的渲染器状态来抑制结果。
- 侧边栏结果状态与通知收件箱及其读取/确认生命周期保持一致。

## 考虑过的替代方案

### 仅对选中的行隐藏完成图标

被拒绝：这会在存储中留下陈旧的未读状态，并且无法阻止持久化或原生通知。

### 仅依赖 React 查看上下文 effect

被拒绝：该 effect 是异步的，可能在快速完成或渲染器导航时输掉竞态。提示时的快照在不信任渲染器焦点、也不绕过主进程安全失败检查的前提下，关闭了调度边界。
