# ADR 0149：平稳的对话记录运行状态动效

> **翻译说明：** 本页是与 [英文源决策](/adr/0149-calm-transcript-running-status-motion) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-09-04
- 决策者：PI-Desktop core
- 相关：D071, D290, E2E-053, E2E-083

## 上下文

对话记录曾在流式输出前的 Working 指示器以及活动的思考/工具标签文本中，使用裁剪进文字的快速渐变微光动效。由于前景高光会逐个字形移动，状态文案的对比度持续变化，在长时间运行中更难扫读。现有的工具 spinner 和流式轨道已经为具体的实时状态提供了动效。

## 决策

运行中的对话记录文案保持为静态、可读的语义文本颜色。流式输出前的 Working 指示器新增一个紧凑的三点标记，带有错开的 1 秒不透明度/缩放脉冲。活动的思考与工具标签使用一个小的状态标记，配合 1 秒不透明度脉冲，取代文本微光动效。工具 spinner、运行行状态圆点和助手流式轨道保持现有的状态反馈。

所有新增的标记动效在 `prefers-reduced-motion: reduce` 下均被禁用；文本与静态标记仍然可见，因此状态绝不会仅通过动效传达。协议、持久化、运行时或本地化契约均无变更。

## 后果

- Working 与活动的工具标签在每一动画帧都保持清晰可读。
- 对话记录只有一种克制的加载表达方式：可读的文案加一个小的状态标记，文字之上不再有移动的高光。
- 测试与渲染审查应同时验证浅色/深色主题和减弱动效模式，尤其是在某个回合尚未产生首个事件时。

## 被否决的备选方案

- 保留文本微光动效并放慢速度：更慢的对比度变化仍然会让标签本身不稳定，而且几乎不能提供额外的状态信息。
- 用大卡片或进度时间线替换状态：这会为一个只需等待信号的瞬态状态增加装饰性表面和密度。
