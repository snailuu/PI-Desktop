# ADR 0150：内联 SVG 空主页代理标记

> **翻译说明：** 本页是与 [英文源决策](/adr/0150-inline-svg-empty-home-agent-mark) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

## 上下文

空主页 hero 区域此前使用的是一张光栅精灵图集，其中包含随机的姿势组、离散的帧切换，以及一个可加速播放的悬停快捷键。其结果是在中央对话区域视觉上过于喧闹，并且为一个装饰性标记引入了资源、定时器以及减少动态效果状态。

## 决策

将该精灵图替换为一个 100px 的内联 SVG 代理标记。一条细轨道和信号点围绕一个紧凑的核心缓慢旋转；核心轻柔地呼吸，眼睛偶尔眨动。动画是确定性的，指针悬停不会改变其节奏，并且 `prefers-reduced-motion: reduce` 会冻结该标记。该 SVG 仍然是装饰性的，带有 `aria-hidden=\"true\"`，并保留现有的 100px 布局槽位。

## 后果

- 空主页的品牌形象更加安静，并通过语义化颜色 token 在浅色与深色主题下保持可读性。
- 该组件不再拥有光栅图集、随机选择、定时器或悬停状态。
- CSS 负责动态效果，可以在不改变所渲染 SVG 的情况下将其禁用。
- 旧的精灵图资源可以保留以供历史源码上下文使用，但不再是渲染器路径的一部分。

## 被拒绝的替代方案

- 保留现有图集并调整暂停时长：这会保留视觉上嘈杂的像素艺术处理方式以及特定于交互的定时器状态。
- 生成另一个光栅吉祥物：这会增加资源维护成本，同时保留相同的主题与减少动态效果限制。
