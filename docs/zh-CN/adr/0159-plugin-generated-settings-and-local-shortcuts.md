# ADR 0159：生成的插件设置与插件本地快捷键

> **翻译说明：** 本页是与 [英文源决策](/adr/0159-plugin-generated-settings-and-local-shortcuts) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-08-13
- 决策负责人：PI-Desktop desktop/plugin 维护者

## 背景

插件已经可以声明设置，并且能够读写自己的私有设置，但用户没有标准方式来编辑这些值。下一个已知的设置是快捷键，而在插件设置契约稳定之前，将插件快捷键全局注册会扩大冲突面和生命周期影响范围。

## 决策

1. `contributes.settings` 是生成的设置 UI 的事实来源。支持的类型为 `string`、`number`、`boolean`、`select`、`json` 和 `shortcut`。
2. 快捷键设置通过 `command` 声明一个插件命令，并具有固定的 `scope: "plugin"`。用户可以在已安装插件页面中编辑它。
3. 插件快捷键仅在 PI-Desktop 窗口获得焦点时由渲染器处理。主机在执行命令前会重新检查插件激活范围。它们不是 Electron/全局快捷键。
4. 主机验证值，将其持久化到插件私有设置文件中，并向插件进程发送 `plugin:settingsChanged`。
5. 在专门的安全存储契约设计完成之前，密钥类设置仍被拒绝。

## 后果

- 插件作者无需打包自定义配置页面，即可提供可用的设置界面。
- 现有的应用快捷键映射仍然是应用全局行为的权威来源，插件快捷键不能替换它。
- 未来的全局插件快捷键功能将需要单独的决策，以处理冲突、操作系统注册以及已禁用/后台插件状态。
