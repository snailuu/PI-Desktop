# ADR 0161：与 Language 一致的可搜索主题选择器

> **翻译说明：** 本页是与 [英文源决策](/adr/0161-searchable-theme-picker) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-09-05
- 决策负责人：PI-Desktop 桌面/设置维护者
- 相关：D316、D314、ADR 0160、D175

## 上下文

设置 → 常规 → 外观将主题呈现为三张预览卡片（System / Light / Dark），插件主题则换行进入同一网格。Language 和 Font 已经是可搜索的选择器行。插件主题使卡片网格换行超出三列，而且视觉预览图无法随贡献的调色板缩放。Language 选择器已经解决了同样的列表增长问题。

## 决策

1. 主题是一个可搜索的选择器行，与 Language 采用相同的锚定菜单模式：触发器填满设置控件列，菜单通过 portal 渲染，因此设置卡片不会将其裁剪，搜索可过滤列表。
2. 内置的 System、Light 和 Dark 固定置顶。插件主题在分隔线之后排列，并带有现有的"Provided by …"提示。搜索可匹配标签、描述、id 和插件 id。
3. `AppSettings.theme` 保持不变（`system` | `light` | `dark` | `plugin:<pluginId>:<themeId>`）。不可用的插件主题仍回退到 `system`。
4. 这修订了 ADR 0160 中关于 Appearance 将 Theme 保留为三张预览卡片的条款。

## 后果

- Appearance 的三行——Theme、Language、Font——共享同一种控件模式。
- 插件主题不再使三列卡片网格换行。
- 添加插件主题不会改变选择器外观。

## 备选方案

- 保留主题为换行的预览卡片：一旦插件添加超过一两个调色板，就会难以阅读，且与 Language 不一致。
- 在选择器行内保留迷你窗口预览图：为一种一选中就立即可见的选择增加额外外观元素。
