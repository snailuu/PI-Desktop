# ADR 0184：将上下文使用情况检查器停靠到输入框工具栏

> **翻译说明：** 本页是与 [英文源决策](/adr/0184-composer-context-usage-inspector) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-09-08
- 决策者：PI-Desktop 渲染器与 UX 维护者
- 修订：D103、D184、D244、ADR 0047、ADR 0103
- 相关：D347、E2E-060d、US-UI-61

## 上下文

紧凑的上下文检查器（ADR 0047、ADR 0103）挂在最新的助手回合下方。当转录内容滚动后，常规的剩余容量检查需要先找到那一行。协作者一致同意把这唯一入口移到模型选择器旁边，而不是保留两份相同的数字。

## 决策

1. 在输入框右侧工具栏中渲染一个上下文检查器，紧邻合并的模型 × 推理芯片的左侧。在活动会话有使用数据之前隐藏它。
2. 保持数据契约：剩余容量、已用/窗口计数、回合总量、已完成回合速度、供应商原始值、聚合工具摘要，以及最新的压缩行，仍然描述最近一次报告了使用情况的助手回合。之后一个没有总量的流式回合不会抢走该回合的工具或吞吐量。委派行的使用数据不会驱动环。压缩标记仍然会拆分溢出重试回合，因此检查器不会把失败尝试与重试相加。
3. 保留点击/键盘触发、剩余容量环、感知视口的主体门户、外部点击关闭以及 Escape 行为。触发器只显示环和百分比；由于无障碍名称已经说明了剩余容量，因此省略了多余的 `Context` 标签。
4. 保留紧凑摘要内容。标题为剩余 token 加百分比。下方各行采用统一的弱化标签 / 等宽数字取值节奏，以间距分隔。弹出层保留其浮层边缘，不绘制内部分隔线（D297）。
5. 已完成回合下的助手元信息保留可选的模型徽章和无使用数据的吞吐量回退。它不再承载检查器。
6. 仅渲染器改动：无协议、存储、运行时核算或模型元数据改动。

## 后果

- 在撰写时剩余容量仍可访问，即使转录已经滚动。
- 历史回合不再暴露逐行检查器；输入框芯片是最新使用情况快照的唯一权威。
- 当空间允许时，面板仍在停靠点上方打开，因为放置已经优先选择有空间的一侧并会钳制到视口内。

## 被拒绝的备选方案

- **保留消息行检查器并新增第二个输入框入口：** 两个界面会显示相同的数字，让用户不确定哪个是权威的。
- **弹出层各部分之间的内部细线：** 被 D297 拒绝；浮层保留外边缘，而不是内部分隔线。标题的双重横线通过去掉额外的标题说明来修复，而不是添加边框。
