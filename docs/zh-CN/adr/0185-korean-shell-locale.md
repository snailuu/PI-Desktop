# ADR 0185：韩语 shell 区域设置

> **翻译说明：** 本页是与 [英文源决策](/adr/0185-korean-shell-locale) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-09-09
- 决策负责人：PI-Desktop desktop/i18n 维护者
- 相关：ADR 0160、ADR 0182、ADR 0183、D349、E2E-091

## 上下文

可搜索的区域设置注册表已经支持完整的 shell 目录，但韩语用户仍只能使用英语或其他已发布的区域设置。韩语是一门独立的语言，不应通过英语回退或带有韩语标签的中文目录来表示。

## 决策

1. 在 `packages/i18n/src/locales/ko` 提供完整的韩语 shell 目录，原生名称为 `한국어`，英文名称为 `Korean`。
2. 将 `ko` 以及区域性的 `ko-*` 操作系统区域设置标签解析到韩语目录。将 `ko` 添加到持久化的 `AppSettings.language` 以及 Electron Chromium 的区域设置允许列表中。
3. 提供韩语产品变更日志目录，其稳定版本与高亮条目数量集合与英语保持一致，使发布说明跟随当前生效的 shell 区域设置。
4. 保持现有的英语优先目录约定：键、插值变量、可搜索选择器行为，以及对插件贡献标签的英语回退均保持一致。不改变主机协议、存储 schema 或 IPC 版本。

## 后果

- 韩语用户可以选择韩语或使用自动检测，而无需重新加载渲染器。
- 目录与变更日志的一致性测试将韩语与现有已发布的区域设置一并覆盖。
- 区域性韩语变体有意共享一个基础目录；后续可以在不改变选择器约定的前提下添加拼写差异。

## 备选方案

- 注册 `ko` 但回退到英语：拒绝，因为选择器会宣称提供未翻译的 shell。
- 立即添加区域特定的韩语目录：拒绝，因为当前的区域设置约定为每种语言使用一个可维护的目录。
