# ADR 0186：使用主进程拥有的一次性调用总结首回合会话标题

> **翻译说明：** 本页是与 [英文源决策](/adr/0186-session-auto-title-summary) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- 状态：已接受
- 日期：2026-09-08

## 上下文

首个提示词当前需要立即在侧边栏显示标签，但原始截断的提示词噪声较大，且可能掩盖任务主题。标题总结必须使用与会话相同的供应商/模型，同时不能将模型执行移入渲染器，也不能更改宿主拥有的会话存储。

## 决策

从渲染器的角度来看，规范化首提示词回退保持同步。在初始回合发出 `agent_end` 后，渲染器调用允许列表中的 `session/summarizeTitle` IPC。Electron 校验会话和提示词，解析会话的有效供应商/模型，并在禁用思考的情况下调用 agent-runtime 的 `summarizeSessionTitle` 一次性调用。运行时对响应进行清理，空完成或失败完成会保持回退不变。渲染器通过现有的 `session.rename` 路径持久化有效结果。

渲染器本地的会话元数据持久化 `manualTitle`。自动路径也会拒绝为既非已识别默认值也非确定性首提示词回退的持久化标题运行。这保护了标记存在之前创建的手动标题，并防止已完成的总结在后续渲染器重启时被替换。宿主 RPC 或存储 schema 版本均无变更。

## 影响

- 新会话会立即获得可读的回退标签，并在配置的供应商成功时获得简洁的后台总结。
- 手动标题在渲染器重启后仍保持权威。
- 供应商故障不会阻塞或导致对话回合失败。
- 标题总结 IPC 归主进程拥有，不会向渲染器暴露供应商凭证或模型执行。

## 考虑过的替代方案

- 在渲染器中运行一次性调用：已拒绝，因为供应商解析和凭证属于 Electron 主进程和 sidecar。
- 在提交提示词前等待总结：已拒绝，因为它会给每个首回合增加可见延迟。
- 为标题来源添加宿主 schema 列：已推迟；持久化的渲染器元数据加上标题/回退防护即可覆盖现有和新会话，无需存储迁移。
