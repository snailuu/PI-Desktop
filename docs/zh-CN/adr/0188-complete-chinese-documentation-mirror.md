# ADR 0188：完成中文文档镜像

> **翻译说明：** 本页是与 [英文源决策](/adr/0188-complete-chinese-documentation-mirror) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

- **状态：** 已接受
- **日期：** 2026-09-09
- **修订：** ADR 0079

## 上下文

ADR 0079 将中文站点限定为一个翻译的引导层，外加针对 `docs/spec/` 的逐路径对照页面。VitePress 通过在当前路径前加上语言区域前缀来构建备用语言区域的 URL，而从不检查目标页面是否存在，因此每个没有中文对应页面的页面——ADR、项目记录以及 docs 的 README——都会从语言切换器产生 404。仅存在于中文的导航页面在反方向上也产生同样的 404。该语言区域门禁也只覆盖规格说明树，因此 ADR 与项目记录的覆盖缺口是隐形的。

## 决策

1. 逐路径镜像每一棵文档树：`spec/`、`adr/`、`project/`、`guide/`、`plugin-development.md` 以及 docs 的 `README.md` 在 `docs/zh-CN/` 下都有具有相同相对路径与路由的简体中文对应页面。
2. 保持英文为规范版本。每个中文页面都带有指向其英文路由的翻译声明；代码、协议字段、标识符与链接目标保持不变。
3. 为仅存在于中文的导航页面添加英文对应页面：规格说明地图、其八个主题着陆页，以及精选的 ADR 入口。
4. 将 `pnpm docs:check` 从规格说明树扩展到每一棵镜像树的双向检查，并包含结构保真检查（标题、代码块、表格行与单元格）以及悬空 `/zh-CN/` 链接检测。

## 后果

- 语言切换器在两种语言区域的每个页面上都能正常解析；两侧都不缺少镜像路由。
- 文档变更必须在同一次逻辑变更中同步更新中文对照页面，且当某个页面、表格行或代码块缺失时门禁会失败。
- 机器辅助翻译现在覆盖 ADR 与项目记录；当某项决策发生变化时，评审者仍负责术语的准确性。
- 中文镜像是一个完整的维护面，而非引导层，因此翻译工作成为每次文档变更的一部分。

## 备选方案

- 在未翻译的页面上隐藏或重定向语言切换器：不予采纳，因为这会使中文站点不完整，并且使纯英文页面只能靠偶然机会被访问到。
- 仅翻译 ADR 索引而让记录保持英文：不予采纳，因为中文导航仍会落到英文页面上。
- 将门禁范围限定在规格说明：不予采纳，因为 ADR 与项目记录的镜像会在无人察觉的情况下持续偏离。
