# 架构决策记录

> **翻译说明：** 本页是与 [英文源决策](/adr/README) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

ADR 记录那些不应被悄然更改的决策。

[中文 ADR 镜像](/zh-CN/adr/README) 在同一相对路径下翻译每一条记录，而[精选 ADR 入口](/zh-CN/adr/) 则提供了一条更短的阅读路径，通向同一组记录。决策 ID、状态以及英文记录仍是两个语言版本共同的事实来源。

## 格式

每条 ADR 包含：

- 状态
- 上下文
- 决策
- 影响
- 备选方案（可选）
