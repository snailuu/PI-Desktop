# 文档重设计视觉验证

> **翻译说明：** 本页是与 [英文源文档](/project/2026-08-13-docs-redesign-verification) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

## 验证契约

- 视口：桌面端 1440×900，移动端 390×844。
- 语言环境：英语和简体中文。
- 外观：浏览器运行期间会检查浅色和深色模式；提交的截图使用浅色模式，以便在仓库查看器中保持可读性。
- 溢出：文档根元素必须与视口宽度一致；宽表格和代码块只能在其自身容器内滚动。
