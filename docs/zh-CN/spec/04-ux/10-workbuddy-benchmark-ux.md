## 1. WorkBuddy 是什么（观察所得）

一个面向消费者/专业消费者的“AI 工作伴侣”：以对话为先的桌面应用，其工作单元是
**任务**（一项带目标的对话），组织在**空间/项目**之下，由**专家（人设）· 技能 ·
连接器**的市场加以扩展，另有**自动化**（定时任务）。它高度依赖人设与模板；
PI-Desktop 则偏重开发者与工作区。这里有价值的是交互模式，而非产品范围。

## 2. 观察到的信息架构

```text
+----------------------------+------------------------------------------+
| 侧边栏                      | 主面板                                    |
|  收起 · 搜索 · 筛选 (顶部)   |  各目标页面的头部（标签页/操作）            |
|  新建任务                   |  内容                                     |
|  助理 (本地助理)             |                                          |
|  项目 (Projects)            |  对话目标页：                              |
|  专家·技能·连接器 (浮出菜单)  |   对话记录 + 悬浮输入框                    |
|  自动化 (Automations)       |   输入框：+ · 权限选择 · 模型选择 ·          |
|  更多 (浮出菜单：文件/知识库/ |            语音 · 发送                     |
|        灵感)                |   AI 内容免责声明页脚                      |
|  任务 (N)  — 最近任务        |                                          |
|  空间 (N)  — 空间           |                                          |
|  页脚：头像 · 通知 · 分享     |                                          |
+----------------------------+------------------------------------------+
```

各屏幕的显著细节：

- **对话/任务**：标题位于头部，带搜索/分享/历史/面板
  图标；每条消息带操作行（复制、赞/踩、TTS、重试、分享、更多）
  并内联显示 **token 消耗标签**（`共消耗 ◇2.85`）与模型徽章；全局
  免责声明“内容由 AI 生成，请核实重要信息”位于输入框下方。
- **输入框**：单个胶囊形；占位符演示语法（“@ 引用对话文件，
  / 调用技能与指令”）；左侧一组 `+` 和一个 **权限模式下拉菜单**
  （“默认权限”）；右侧一组模型选择器（“Auto”/具名模型）、麦克风、发送。
- **助理（Assistant）**：一个常驻的“本地助理”对话，
  **连接状态显示在头部**（“已连接：微信小程序” + 齿轮）——助理
  被呈现为一个带集成的实体，而不仅仅是一个线程。
- **项目（Projects）**：落地页带主视觉区（标题、一句话价值主张、
  插图）、主 CTA“新建项目”、“我的项目”卡片列表带 kebab
  菜单，以及 **“从模版创建”模板库**（PRD 流程、市场调研、
  团队知识库、交付、bug 跟踪）。
- **自动化（Automations）**：标签页为定时任务 / 运行记录；空状态（图标 +
  一句话 + 主 CTA）；其下方是约 12 个配方的 **模板库**
  （每日 AI 新闻、周报、会议准备……），因此空状态仍然
  提供一键价值。
- **专家·技能·连接器**：侧边栏项打开一个三向浮出菜单；页面带
  分段标签页（专家/技能/连接器）、搜索、“我的专家”、
  特色场景横幅卡片、分类 chip 行、排序（综合/最热/最新），以及丰富的
  人设卡片（头像、标语、能力标签）。
- **更多**：用于次级目标页面的溢出浮出菜单（我的文件、腾讯文档、
  ima 知识库、乐享知识库、灵感）——让侧边栏保持在约 6 个主项。
- **我的文件（My Files）**：不是文件管理器——而是**任务产出的工件浏览器**。
