# 输入框提示词增强

> **翻译说明：** 本页是与 [英文源规格](/spec/04-ux/12-prompt-enhancement) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。

## 1. 范围

提示词增强功能支持对非空草稿执行一次性的 `Enhance prompt` 请求。输入框将其渲染为一个独立的 Sparkles 操作，位于组合的模型 × 推理选择器和单个 Stop/Send 提交槽之间。调用时，该请求仅使用输入框中当前显示的模型重写草稿文本。文件引用标签保持不变。

这是一个 v1 实用操作，而非代理回合：它不会追加消息、读取会话历史、运行工具或持久化转录行。

## 2. 可用性与交互

仅当以下所有条件都满足时，Sparkles 操作才会启用：

- 草稿在修剪后非空；
- 有效显示的供应商/模型已启用并已认证，使用与 Send 相同的就绪谓词；并且
- 修剪后的草稿不以 `/` 开头。

请求运行期间，该操作被禁用，并显示共享的 `.tool-spinner` 以及本地化的 `Enhancing…` 标签。发送仍然允许。输入框从当前显示的模型选择器发送 `providerId`、`modelId` 和 `thinkingLevel`；主进程验证这些值，并在快照缺失或过期时依次回退到会话、草稿、全局和供应商默认值。

成功时，修剪后的结果替换文本，光标移动到末尾，并且单个 `Undo enhancement` 操作可恢复增强前的确切文本。任何用户编辑、发送或输入框会话切换都会清除撤销操作。没有多级历史记录、键盘快捷键或取消操作。

## 3. 请求与供应商边界

渲染器请求使用允许列表中的 `pi-desktop/prompt/enhance` 调用通道。Electron 主进程通过与代理回合相同的运行时启动解析器来解析有效的供应商/模型，仅在主进程中读取 API 凭据，并调用 agent-runtime 的一次性补全辅助函数。供应商 OAuth 提供商通过现有的主进程拥有的解析器接收短期有效的 `ModelAuth`；没有密钥或刷新令牌进入渲染器。

补全上下文恰好包含：1. 来自 `packages/agent-runtime/src/prompt-templates.ts` 的静态 `PROMPT_ENHANCEMENT_SYSTEM_PROMPT`；以及 2. 一条用户消息，`Draft:\n<draft>`。

不包含任何先前的对话、工具、附件或可配置模板。所选的思考级别传递给 pi-ai，供应商设置重试使用现有的有界重试控制器。当解析出的供应商为 OpenCode Go（或另一个 `opencode.ai` 主机）时，一次性请求将输入框会话 ID 作为 `x-opencode-session` 转发；没有会话的请求会获得一个每次调用唯一的 ID。模型输出作为纯文本消费并修剪。空输出或仅包含空白的输出会导致 `PROMPT_ENHANCEMENT_EMPTY` 失败。

## 4. 失败与竞态处理

失败时保留当前草稿，并渲染一个可关闭的输入框错误栏，其中包含分类后的错误消息和代码。现有的供应商代码如 `PROVIDER_UNAUTHORIZED`、`NETWORK_ERROR` 和 `TIMEOUT` 会被复用。

渲染器在启动请求时捕获草稿键和编辑代际。如果草稿发生更改、被发送/清除，或者用户在响应到达之前切换会话，则该响应将被丢弃，并且不能覆盖较新的草稿。文件标签不包含在重写中，也不会因成功或失败而被移除。
